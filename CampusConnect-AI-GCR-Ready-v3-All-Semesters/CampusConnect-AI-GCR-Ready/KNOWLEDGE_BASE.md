# CampusConnect AI — Academic Knowledge Base

This deployment contains the official Panjab University 2026–2027 M.Sc. (Hons.) Computer Science (Specialization in Data Science) syllabus data used by the chatbot.

## Coverage
- Semester 1 through Semester 4
- All 17 papers/academic components
- Paper codes, names, categories, marks and credits
- Subject objectives and outcomes where present in the source
- Unit-wise syllabus for the 12 theory subjects
- Recommended books where present in the source
- Minor-project practical information
- Major Project (MDS-2616) report requirements
- Seminar (MDS-2617) information

## Source-of-truth rule
The chatbot must not invent university-specific information. If exact information is absent from the supplied official data, it should respond with:

> Not available in the provided document.

The data file is `data/pu-data-science-2026-27.json`.
